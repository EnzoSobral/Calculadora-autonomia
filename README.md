## 📌 Sobre o projeto

Este projeto é uma aplicação simples e intuitiva desenvolvida para calcular a autonomia de veículos elétricos com base no consumo de energia e na capacidade da bateria.

A ideia é ajudar o usuário a entender, de forma rápida e prática, quantos quilômetros um carro elétrico pode percorrer em diferentes cenários.

---

## ⚙️ Funcionalidades

- Cálculo automático da autonomia do veículo  
- Suporte a valores decimais para maior precisão  
- Interface simples e fácil de usar  
- Resultados em tempo real  

---

## 🧮 Como funciona

O usuário informa:

- Consumo do veículo (km/kWh)  
- Capacidade da bateria (kWh)  

E o sistema retorna automaticamente:

- Autonomia estimada em quilômetros

## 🎯 Objetivo

O objetivo do projeto é demonstrar como conceitos simples de matemática podem ser aplicados na prática para resolver problemas reais, como o planejamento de viagens com veículos elétricos.
